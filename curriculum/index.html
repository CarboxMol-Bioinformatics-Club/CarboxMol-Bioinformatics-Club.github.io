28 Həftəlik Bioinformatika və Tədqiqat Sillabusu

Klubun sillabusu beynəlxalq standartlar əsasında hazırlanmışdır: Payız semestrində alqoritmik təməl və 3D struktur biologiyası, Yaz semestrində isə tətbiqi Omics məlumat elmi və tələbə hakatonu əhatə olunur.

I Semestr: Hesablama Biologiyasının Əsasları və Struktur Genomika

Həftə 01–03: Təməl Mühit

Linux Bash terminal əmrləri, FASTA/FASTQ/SAM/BAM fayl standartları və NCBI/UniProt bazaları.

Həftə 04–08: Python & Biopython

Python sintaksisi, Biopython Seq/SeqIO modulları, Needleman-Wunsch və BLAST hevristik axtarışları.

Həftə 09–12: Struktur Biologiyası

AlphaFold DB, PyMOL, ChimeraX, Coot, Carbox və CarboxMol ilə 3D zülal konformasiyaları və koordinat analizi.

Həftə 13–14: Təkamül & Bio-Quiz

Clustal Omega filogenetik ağaclar, I Semestr yekun elmi debatı və interaktiv bilik yarışması.

II Semestr: Tətbiqi Omics Data Science, Süni İntellekt və Tələbə Hakatonu

Həftə 15–18: R & Bioconductor

R proqramlaşdırma dili, ggplot2 nəşr səviyyəli vizuallaşdırma, GenomicRanges və NGS keyfiyyət süzgəcləri.

Həftə 19–23: RNA-Seq & Xərçəng Genomikası

STAR/HISAT2 hizalama, DESeq2 diferensial gen ifadəsi (DGE), Volcano plot, istilik xəritələri və GO zənginləşdirmə.

Həftə 24–25: Dərman Dizaynı & ML

AutoDock Vina molekulyar dokinq, zülal-liqand rabitə enerjisi və Scikit-learn maşın öyrənməsi ilə xərçəng biomarkerləri.

Həftə 26–28: Hakaton və Elmi Sərgi

WCU Bio-Data Hakaton komanda layihələri, mentor saatları və universitet rəhbərliyi qarşısında poster müdafiəsi.
