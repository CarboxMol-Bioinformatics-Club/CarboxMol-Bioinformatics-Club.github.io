## 3. Platform Capabilities

1. **Progressive Web App (PWA) and Offline Execution:** Operates across desktop and mobile browsers with offline caching support.
2. **Interactive Bioinformatics Tools:** DNA/RNA/Protein sequence analysis (`SeqAnalyzer`), Bioconductor R workflows, and 3D macromolecular structure inspection (**Carbox** & **CarboxMol**).
3. **CarboxMol BioMeet:** Virtual seminar rooms and lecture session archives.
4. **Official Bylaws and Curriculum Viewer:** In-browser reader and downloadable PDF/DOCX packages for the 28-week academic syllabus and club charter.
5. **Student and Instructor Portals:** Membership registration, laboratory task tracking, and academic evaluation tools.
